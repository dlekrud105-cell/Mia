### 1. AgriciDaniel/claude-seo
링크: https://github.com/AgriciDaniel/claude-seo  ⭐ 31,357 · 최근 push 2026-11-16 (검색 API 기준) · MIT

**뭐 하는 건데:** Claude Code에 `/seo` 명령을 추가하는 플러그인이다. `/seo audit`은 여러 에이전트가 사이트를 나눠 점검해 우선순위가 매겨진 Markdown 리포트를 만들고, `/seo local`은 Google 비즈니스 프로필·NAP(상호·주소·전화) 일관성·LocalBusiness 스키마·주요 디렉터리 등록 여부를 본다. (README와 skills/seo-local, skills/seo-maps 파일 직접 확인)

**미아한테 왜:** 지금 감으로 하는 "유어페인터 사이트가 시드니 지역 검색에 잘 잡히게 하려면 뭘 고쳐야 하나" 판단을, 근거가 붙은 수정 목록으로 바꿔 준다. seo-local 스킬에 Home Services 업종(service area, free estimate, licensed/insured) 분류가 따로 있어 페인팅 회사에 그대로 맞는다. 나온 스키마 수정안은 기존처럼 WordPress REST API로 Claude Code에게 반영시키면 된다.

**바로 해볼 것:** Claude Code에서 `/plugin marketplace add AgriciDaniel/claude-seo` → `/plugin install claude-seo@agricidaniel-claude-seo` → `/seo setup` 후 `/seo local https://(유어페인터 도메인)` 한 번만 돌려 본다. 전체 감사(`/seo audit`)는 사용량이 크니 나중에.

**걸리는 점:**
- 무료 범위에서는 지역 순위 격자(geo-grid), 실시간 GBP 프로필·리뷰 분석, 로컬팩 실제 순위가 빠진다. 이건 DataForSEO 유료 연동이 있어야 된다고 스킬 파일에 적혀 있다. 무료로는 "사이트에 보이는 정보 기준 점검"까지다. (직접 확인)
- 전체 감사는 일부 에이전트가 Opus로 돌아서 Claude 플랜 사용량을 많이 쓴다고 README에 명시돼 있다.
- 11-10에 브리핑한 crawlseo(Search Console 대시보드)와 일부 겹친다. crawlseo는 "숫자 추적", 이건 "무엇을 고칠지 진단"으로 나눠 쓰면 된다.
- 같은 저자의 유료 커뮤니티(Skool) 홍보가 README에 섞여 있다. 공개판만으로 동작한다고 적혀 있고, 유료 가입은 필요 없다.
- Python 3.11 이상 필요. 미아 맥의 Python 버전은 확인하지 못했다(`/seo doctor`로 확인 가능).
- 실제로 설치해서 돌려 보지는 않았다. 리포트 품질은 README 예시만 봤다.
