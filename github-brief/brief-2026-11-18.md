### 1. jub0t/Concat
링크: https://github.com/jub0t/Concat  ⭐ 18,635 · 최근 push 2026-11-18 (검색 API 기준) · 2026-08 생성, 베타

**뭐 하는 건데:** macOS(Intel·Apple silicon)/Windows/Linux에서 도는 무료 영상 편집기다. 자동 자막, TTS·음성 복제, 배경 제거, 키프레임, 멀티트랙, 4K 내보내기를 전부 로컬 모델로 처리하고 워터마크·계정이 없다. `concat --mcp`로 MCP 서버를 띄우면 에이전트가 프로젝트 생성, 미디어 가져오기, 자르기, 타이틀·자막(`captions_add`), 단어별 강조색(`title_style_words`), 효과, 프레임 미리보기, 내보내기까지 할 수 있다. (README와 docs/MCP.md 직접 확인)

**미아한테 왜:** 지금 CapCut에서 손으로 하는 매물 투어 영상(비전에셋tv)과 유피 에피소드의 컷 이어붙이기·자막 넣기를, Claude Code가 Concat 프로젝트로 1차 조립해 두고 미아는 타이밍만 창에서 고치는 방식으로 바꿀 수 있다. 저장소에 있는 `tools/property_tour.py`(ffmpeg로 이어붙여 MP4만 냄)와 달리 결과가 다시 편집 가능한 프로젝트로 남는다.

**바로 해볼 것:** concat.standalones.org에서 맥 빌드를 받아 설치 → 열리지 않으면 `xattr -dr com.apple.quarantine /Applications/Concat.app` → Claude Code에서 `claude mcp add concat -- /Applications/Concat.app/Contents/MacOS/concat --mcp` 후 "이 폴더 클립 5개를 순서대로 이어 붙이고 자막 넣어서 프로젝트로 저장해줘"라고 시켜 본다.

**걸리는 점:**
- 베타다. README가 "아직 거친 데가 있다"고 직접 적고 있고, 생긴 지 3개월 된 프로젝트다.
- 맥 빌드가 서명되지 않았다(위 xattr 명령 필요).
- 에이전트는 자기 프로젝트만 편집한다. 미아가 창에 열어 둔 프로젝트를 실시간으로 같이 고치는 기능은 아직 없고 계획 단계(#337)다. 에이전트가 만든 프로젝트를 저장한 뒤 창에서 여는 순서로 써야 한다.
- 한국어 자동 자막 품질, Apple silicon에서의 속도, 모델 크기는 확인 못 했다(시스템 요구사항이 웹사이트에만 있음).
- 이미 브리핑한 ffmpeg-skill(11-13)과 겹치는 면이 있다. 차이는 Concat은 사람이 열어 고칠 수 있는 타임라인이 남고, 자막·TTS 모델이 내장돼 있다는 점이다. 둘 다 깔 필요는 없다.
- CapCut 프로젝트와 호환되지는 않는다(호환 언급 없음). CapCut을 대체할지 병행할지는 써 보고 정할 일이다.
- 이 세션에서 직접 설치·실행해 보지는 않았다.
