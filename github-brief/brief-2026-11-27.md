**바로 해볼 것:** Releases에서 맥 설치 파일을 받아 설치하고 "설정 › 일반 › 폴더에 저장"을 켠 다음, 비전에셋tv 영상 하나를 유튜브로 틀어 한국어 인식·영어 번역 품질과 저장된 Markdown을 확인한다.

**걸리는 점:**

- 내 목소리는 말하기 키를 누르고 말한 것만 기록된다고 README에 써 있다. 그냥 말한 내 발언이 대본에 빠질 수 있다 — 상대방 발언 위주 기록이 된다는 뜻. 꽤 큰 제약.
- 통화 녹음 전에 상대방 동의를 받아야 한다(NSW 법상 녹음 동의 요건 — 법적 판단은 별도 확인 필요).
- macOS 14.4 이상 필요, macOS 14.4~15에서는 시스템 받아쓰기를 켜고 한국어를 추가해야 한다. 생성 4주 된 프로젝트, 중국 시장 중심(Feishu, DingTalk 연동 위주). 한국어 인식 품질은 실제로 돌려보지 못해 미확인.
