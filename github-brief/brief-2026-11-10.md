### 1. kLOsk/adloop
링크: https://github.com/kLOsk/adloop  ⭐ 298 · 최근 푸시 2026-11-10 (API 메타데이터 기준, 커밋 페이지는 접근 못 함)

**뭐 하는 건데:** Claude Code에 Google Ads·GA4·Search Console(+Reddit/Microsoft Ads) 도구를 붙인다. 광고 클릭→GA4 세션→전환을 캠페인별로 묶어 실제 CPA를 계산하고, 검색어 보고서에서 제외 키워드를 추가하는 등 쓰기 작업은 "초안→미리보기→승인" 순서로만 실행되고 새 광고는 일시중지 상태로 생성된다. (README 직접 확인)

**미아한테 왜:** 지금 Google Ads 화면과 GA4를 오가며 손으로 맞춰보는 "광고비 대비 실제 문의" 확인과 제외 키워드 정리를 Claude에게 한 문장으로 시키는 걸로 대신한다.

**바로 해볼 것:** Claude Code에게 "`pip install adloop` 후 `adloop init` 마법사 같이 진행해줘"라고 시키고, 첫 호출은 `health_check`.

**걸리는 점:** 본인 Google Cloud 프로젝트(무료)와 OAuth 설정이 필요하고, README상 실계정 접근(Explorer 등급)은 결제수단이 등록된 프로젝트만 승인된다. 읽기 위주라면 이미 연결된 Supermetrics와 겹친다 — 새로 얻는 건 쓰기 작업과 Ads×GA4 교차 분석. Meta 광고는 지원 안 함. 호스팅판(AdLoop Cloud)은 EU 서버 경유.

### 2. crawlseo/crawlseo
링크: https://github.com/crawlseo/crawlseo  ⭐ 690 · 최근 푸시 2026-11-02 (API 메타데이터 기준)

**뭐 하는 건데:** Search Console 데이터, 최대 2,000페이지 사이트 크롤, Core Web Vitals, 순위 추적을 한 대시보드에 모으고 "2페이지 근처 키워드·낮은 CTR·콘텐츠 하락·자기잠식"을 자동으로 짚어준다. 읽기 전용 MCP 서버가 있어 Claude로 질의 가능. (README 직접 확인)

**미아한테 왜:** 유어페인터 WordPress 사이트의 "어떤 지역·서비스 페이지가 순위 11~20위에서 막혀 있나"를 Search Console에서 손으로 필터링하던 일을 대신한다.

**바로 해볼 것:** Claude Code에게 Quick Start(Docker로 DB 띄우고 `npm run dev`) 실행을 시키고, localhost:3000에서 Google 로그인 후 사이트 추가.

**걸리는 점:** Google OAuth 자격증명을 직접 만들어 `.env.local`에 넣어야 함. 키워드 검색량·백링크는 DataForSEO 유료 키가 있어야 하고 없으면 Google 자동완성만 됨. README가 자동 스케줄에 대해 앞뒤가 다르게 적혀 있음("아직 없음" vs Docker 설정 화면) — 확인 필요. Postgres를 띄워두는 맥 상시 실행 부담.

### 3. debpalash/VoiceStudio
링크: https://github.com/debpalash/VoiceStudio  ⭐ 107,106 · 최근 푸시 2026-11-10 (API 메타데이터 기준)

**뭐 하는 건데:** 맥(Apple Silicon, Metal)에서 DMG로 설치하는 로컬 음성 앱. 보이스 클로닝·보이스 디자인, 원본 타이밍에 맞춘 영상 번역 더빙, 받아쓰기, 긴 나레이션 일괄 생성을 하고 로컬 API·MCP도 있다. (README 직접 확인)

**미아한테 왜:** 유피 에피소드 캐릭터 목소리와 비전에셋tv 영상의 영어↔한국어 더빙을 클라우드 TTS 크레딧 없이 맥에서 직접 만든다.

**바로 해볼 것:** Releases에서 DMG 받아 설치 → 기본 엔진(OmniVoice)으로 한국어 문장 3개 생성해서 품질부터 듣기.

**걸리는 점:** 한국어 음질은 README로 확인 못 함 — 646개 언어 지원은 주장일 뿐, 직접 들어봐야 한다. 모델별로 라이선스가 따로 있어 유튜브 수익화 시 상업 이용 가능한 모델인지 Model Manager에서 확인 필요. 7개월 만에 10만 스타는 이례적이라 과대평가 가능성 있음. 립싱크 기능은 없음(Kling 단계는 그대로).

### 4. RamsesAguirre777/facebook-ads-library-mcp
링크: https://github.com/RamsesAguirre777/facebook-ads-library-mcp  ⭐ 289 · 최근 푸시 2026-08-29 (API 메타데이터 기준)

**뭐 하는 건데:** 공개 Facebook 광고 라이브러리 페이지를 헤드리스 브라우저로 긁어 광고주·광고 문구·CTA·랜딩 URL·게재 시작일을 구조화해 돌려주는 작은 MCP. API 토큰·페이스북 계정 불필요. (README 직접 확인)

**미아한테 왜:** 시드니 페인팅 경쟁사(또는 분양 개발사)가 지금 돌리는 Meta 광고 문구와 랜딩페이지를 광고 라이브러리에서 하나씩 스크롤하며 보던 일을 "country=AU, 'house painting sydney' 검색해서 광고주별로 묶어줘" 한 줄로 대신한다.

**바로 해볼 것:** Claude Code에게 README의 Install 4줄 실행 + `claude mcp add` 등록을 시키고 `search_ad_library("painter sydney", country="AU")` 호출.

**걸리는 점:** 광고비·노출수는 안 나옴(Meta가 비공개). 페이스북 화면 구조가 바뀌면 깨지는 스크래퍼이고 레이트리밋 처리 없음. 스크래핑이라 Meta 약관상 회색지대. 기본값이 멕시코(MX)라 국가 코드 꼭 지정.
