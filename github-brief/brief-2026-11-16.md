### 1. WordPress/mcp-adapter
링크: https://github.com/WordPress/mcp-adapter  ⭐ 1,922 · 최근 push 2026-11-13

**뭐 하는 건데:** WordPress 6.9 코어에 들어간 Abilities API로 등록한 기능을 MCP 도구로 바꿔, Claude Code 같은 클라이언트가 호출할 수 있게 한다. 연결은 WP-CLI(STDIO) 또는 `@automattic/mcp-wordpress-remote` 프록시 + Application Password(HTTP) 두 방식이다. (README와 docs/guides 직접 확인)

**미아한테 왜:** 지금은 "이번 달 리드 소스별 견적 금액 뽑아줘" 같은 일을 시킬 때마다 Claude Code가 플러그인 REST 엔드포인트를 찾아 curl을 짜는데, 플러그인 기능을 ability로 한 번 등록해 두면 그다음부터는 Claude Code가 '고객 조회', '견적 생성' 같은 도구를 바로 호출한다.

**바로 해볼 것:** 사이트 WP 버전이 6.9 이상인지 먼저 확인하고, README 상단의 WordPress Playground 데모 링크에서 설치 없이 동작을 본다. 실제 사이트에는 스테이징에서 먼저 `wp plugin install https://github.com/WordPress/mcp-adapter/releases/latest/download/mcp-adapter.zip --activate`.

**걸리는 점:**
- 설치만으로는 쓸 게 거의 없다. ability는 기본이 비공개이고, 자체 플러그인에 ability 등록 코드를 추가해야 한다(Claude Code에 시킬 작업, 반나절~하루 규모로 추정). 같은 WordPress 팀의 `WordPress/agent-skills`에 `wp-abilities-audit`(플러그인 REST 엔드포인트를 훑어 ability 등록안을 제안) 스킬이 있어 이 작업에 쓸 수 있다(README 표에서 확인, 실행은 안 해봄).
- WordPress 6.9 이상 필수. 유어페인터 사이트의 현재 버전은 확인 못 했다.
- 버전이 0.x이고 마이그레이션 가이드가 v0.3/v0.5/v0.7 세 개나 있다. 업데이트 때 깨질 수 있다.
- 고객 개인정보가 AI 도구로 노출되는 구조라, ability마다 권한(capability) 설정을 꼭 좁혀야 한다. 기본값은 로그인 사용자 `read` 권한이다.

### 2. chinapandaman/PyPDFForm
링크: https://github.com/chinapandaman/PyPDFForm  ⭐ 1,246 · 최근 push 2026-11-14 · MIT

**뭐 하는 건데:** PDF 양식의 필드 이름·값을 확인하고, 딕셔너리(필드명: 값)로 한 번에 채워 저장하는 Python 라이브러리 겸 CLI. 양식 생성, 페이지 추출·병합도 된다. (README 직접 확인)

**미아한테 왜:** 매번 같은 이름·여권번호·주소·비자 정보를 손으로 다시 입력하는 PDF 양식(이민국 PDF 양식, 펫보험 청구서 등)을 내 정보 파일 하나로 채우게 한다.

**바로 해볼 것:** Claude Code에 "pipx로 `PyPDFForm[cli]` 설치하고, 이 PDF 양식 필드 목록을 뽑은 다음 내 정보 JSON으로 채워줘"라고 시키고, 최근에 손으로 채운 양식 하나로 결과를 비교한다.

**걸리는 점:**
- 채울 수 있는 필드(AcroForm)가 있는 PDF만 된다. 스캔본이나 필드 없는 PDF는 안 된다. 호주 이민국 양식이나 미아 펫보험사 청구서가 어느 쪽인지는 확인 못 했다. 양식마다 첫 단계에서 필드 목록이 나오는지 보면 바로 알 수 있다.
- 비자 신청 대부분은 ImmiAccount 웹 입력이라, 이 도구는 PDF로 내는 부속 양식에만 해당한다.
- 이 세션에서 직접 돌려보지는 않았다.

### 3. FujiwaraChoki/supoclip
링크: https://github.com/FujiwaraChoki/supoclip  ⭐ 3,302 · 최근 push 2026-11-16 · AGPL-3.0 (오늘 Python 트렌딩)

**뭐 하는 건데:** 긴 영상(유튜브 링크나 업로드 파일)을 받아 전사한 뒤, LLM이 클립으로 쓸 만한 구간 3~7개를 골라 얼굴 중심 9:16 세로 크롭, 단어 단위 자막, 상단 훅 제목을 넣어 렌더한다. 편집기와 YouTube/TikTok/Instagram 직접 게시 기능도 있다. (README 직접 확인)

**미아한테 왜:** 비전에셋tv 롱폼 영상에서 쇼츠·릴스용 구간을 찾아 자르고 자막 다는 수작업(지금은 CapCut 등에서 직접 할 것으로 추정)을 초안 단계까지 자동으로 한다.

**바로 해볼 것:** 셀프호스팅 전에 호스팅 버전(supoclip.com)에 비전에셋tv 영상 하나를 넣어 한국어 자막과 구간 선택 품질부터 확인한다. 쓸 만하면 Docker로 맥에 올린다.

**걸리는 점:**
- 기본 구성은 AssemblyAI 키(전사, 유료 종량제)와 LLM 키 하나가 필요하다. README에 Whisper + Ollama 완전 로컬 구성 튜토리얼 링크가 있지만, 그 문서는 열어보지 않았다.
- **한국어 지원은 README에 언급이 없다.** 한국어 전사 정확도, 한국어 자막 폰트, LLM의 한국어 구간 판단 모두 확인 못 했다. 이 브리핑에서 가장 불확실한 부분이다.
- 호스팅 버전의 무료 범위와 가격은 확인 못 했다.
- AGPL이라 개인 사용은 문제없지만, 고쳐서 남에게 서비스로 제공하면 소스 공개 의무가 생긴다.
