### 1. mikusnuz/meta-ads-mcp
링크: https://github.com/mikusnuz/meta-ads-mcp  ⭐ 95 · 최근 커밋 2026-10-19 (npm 1.6.1, 같은 날 배포)

**뭐 하는 건데:** Meta Marketing API v26.0을 MCP 서버로 감싼 것이다. 캠페인·광고세트·광고 조회와 생성·수정·삭제, 인사이트 리포트, 맞춤 타겟, 자동 규칙, 광고 라이브러리 검색이 들어 있다. (README 직접 확인)

**미아한테 왜:** 지금 Meta 광고관리자에서 손으로 보는 "이번 주 유어페인터 광고별 리드 단가 확인 → 기준보다 비싼 광고 끄기"를 Claude Code에게 한 문장으로 시킬 수 있다.

**바로 해볼 것:** Meta 비즈니스 설정에서 `ads_read` 권한만 있는 시스템 사용자 토큰을 발급하고, `npx -y @mikusnuz/meta-ads-mcp`를 Claude Code MCP에 등록한 뒤 "최근 7일 캠페인 인사이트 보여줘"부터 해본다.

**걸리는 점:**
- 읽기 전용 모드가 없다. 삭제 도구(`delete_campaign`, `delete_ad` 등)가 기본 포함이라, 처음엔 읽기 권한 토큰만 쓰거나 Claude Code 권한 설정에서 쓰기 도구를 막는 게 안전하다. (README 직접 확인)
- 개인 개발자 1명이 관리하는 저장소이고 스타가 적다. 광고 계정 토큰을 맡기는 것이니 이 점은 감안해야 한다.
- 이미 연결된 Supermetrics MCP와 조회 기능이 겹친다. Supermetrics로 Meta 광고 수정까지 되는지는 확인하지 못했다. 겹치는 범위가 크면 이건 "수정 작업용"으로만 쓰면 된다.
- 토큰 연장·픽셀 도구는 Meta 앱 ID/시크릿이 있어야 한다. 인스타 자동 포스팅용 Meta 앱이 이미 있으면 그걸 쓰면 되는데, 있는지는 확인 못 함.

### 2. JuneYaooo/rea-video
링크: https://github.com/JuneYaooo/rea-video  ⭐ 11,385 · 최근 커밋 2026-11-20

**뭐 하는 건데:** 영상 파일을 넣으면 컷마다 실사인지 AI 생성인지 코드로 만든 건지 판정하고, 카메라 위치·무빙·조명·자막 타이밍·편집 속도·BPM을 정리한 리포트(HTML/PDF)와 리메이크 계획을 만든다. Claude Code에게 "이 저장소 설치하고 이 영상 분해해줘"라고 하면 에이전트가 CLI를 깔고 돌리는 방식이다. (README 직접 확인)

**미아한테 왜:** 유피 에피소드를 Kling으로 만들기 전에 참고하는 픽사풍 숏폼이나 반응 좋았던 부동산 릴스를 넣으면, 지금 눈으로 돌려보며 하는 컷 수·카메라 무빙·자막 타이밍 분석을 대신 정리해준다.

**바로 해볼 것:** 저장해둔 참고 릴스 하나를 골라 Claude Code에 "Install https://github.com/JuneYaooo/rea-video, then break down this video: (파일 경로)"를 그대로 입력한다.

**걸리는 점:**
- 리포트 언어는 중국어 또는 영어뿐이다. 한국어는 안 된다. (README 직접 확인)
- 컷별 생성 프롬프트(Kling에 바로 넣을 문장)는 Gemini 같은 영상 모델을 API 키로 연결해야 나온다. 키 없이 도는 "도구만 모드"는 무료·오프라인이지만, 인스타·틱톡에서 다운받은 재압축 영상에서는 정확도가 떨어진다고 README가 직접 적어 두었다.
- 만든 지 3주 된 저장소인데 스타가 1만 개를 넘었다. 빠른 스타 증가가 실제 품질을 뜻하는지는 판단 못 함.
- 맥 지원은 README에 명시돼 있지 않다. 요구사항이 ffmpeg와 Python 3.10+뿐이라 돌아갈 가능성은 높지만 확인은 못 함.
