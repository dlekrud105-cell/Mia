### 1. kjellberg/pdfr
링크: https://github.com/kjellberg/pdfr  ⭐ 49 · 최근 push 2026-11-25 (저장소 생성 2026-11-15)

**뭐 하는 건데:** 양식을 채우는 데만 집중한 PDF 뷰어. 입력 필드가 있는 PDF뿐 아니라 선과 칸만 그려진 양식, 스캔한 종이 양식에서도 칸을 자동으로 찾아 클릭 후 타이핑하면 칸 안에 맞는 크기로 들어가고, 날짜·번호용 네모칸에는 한 칸에 한 글자씩 넣는다(README 확인). `claude mcp add pdfr -- pdfr mcp`로 Claude Code에 붙이면 Claude가 칸 라벨을 읽고 대신 채운다(README 확인).

**미아한테 왜:** 펫보험 청구서·수의사 기록 요청서·각종 신청서처럼 입력 필드 없는 PDF에 텍스트 상자를 끌어다 놓고 글자 크기를 맞추던 일을 대신한다. 이름·주소·여권번호 같은 반복 정보는 사람별로 따로 기억해서 다음 양식에 제안해준다(README 확인, 로컬 저장이라고 적혀 있음).

**바로 해볼 것:** 릴리스 페이지에서 macOS용 `.dmg`를 받아 설치 → 최근에 손으로 채웠던 펫보험 청구서 PDF 하나를 열어 칸 인식이 되는지만 확인.

**걸리는 점:**
- (README 확인) 라이선스가 PolyForm Strict — 개인·비영리 용도만 무료. 유어페인터·비전에셋 업무 서류에 쓰면 유료 Business 키가 필요하다. 이민·유피 서류까지만 쓸 것.
- (README 확인) 맥 앱이 아직 공증(notarize)되지 않아 처음 실행할 때 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"를 눌러야 한다. 설치 스크립트(`curl ... | sh`)도 있지만 dmg를 받는 쪽을 권한다.
- (README 확인) 리눅스 우선으로 만든 앱이고 macOS 지원은 최근 추가. 생성된 지 10일 된 신생 프로젝트라 버그 가능성이 있다.
- (확인 못 함) 릴리스 목록 API 접근이 막혀 macOS dmg가 실제로 올라와 있는지는 직접 확인하지 못했다. 한글 입력·한글 폰트가 제대로 들어가는지도 README에 언급이 없다.
- 이민국 양식(Form 80, 1221 등)은 원래 입력 필드가 있는 PDF라 맥 미리보기로도 채워진다. 이 앱의 실제 이득은 필드 없는 양식·스캔 양식에서 나온다. 11-16에 브리핑한 PyPDFForm(필드 있는 양식을 코드로 채움)과 역할이 다르다.
