### 1. heygen-com/hyperframes
링크: https://github.com/heygen-com/hyperframes  ⭐ 88,855 · 최근 push 2026-11-23

**미아한테 왜:** 지금 손으로 만드는 @syd_real_estate_mia 시장 분석 그래픽을 "교외별 중위가격 차트 레이스 15초 세로 영상"처럼 말로 시켜 영상으로 받을 수 있다. 유어페인터 시공 전후 클립에 자막과 텍스트 훅을 얹는 데도 쓸 수 있다.

**바로 해볼 것:** `claude plugin marketplace add heygen-com/hyperframes` → `claude plugin install hyperframes@hyperframes` 후 "/hyperframes로 시드니 3개 교외 가격 비교 10초 차트 영상 만들어줘" 요청.

**걸리는 점:** Node.js 22 이상과 FFmpeg가 필요하다(README 명시). HeyGen 회사 제품이라 Studio 앱은 유료 Pro($25/월)로 유도한다. 로컬 CLI 렌더는 무료다. 한글 폰트 렌더링 품질은 확인하지 못했다.

### 4. WordPress/mcp-adapter
링크: https://github.com/WordPress/mcp-adapter  ⭐ 1,933 · 최근 push 2026-11-21

**뭐 하는 건데:** WordPress 공식 패키지다. 플러그인에 등록한 "Ability"를 MCP 도구로 노출해 Claude Desktop이나 Claude Code가 WP-CLI(STDIO) 또는 `/wp-json/mcp/...` HTTP로 호출할 수 있게 한다. Ability는 기본이 비공개이고, 공개할 것만 직접 지정한다. (README 확인)

**미아한테 왜:** 유어페인터 자체 플러그인(고객 DB, 견적, 광고비 ROI)에 "이번 달 리드 소스별 성사율 조회" 같은 Ability를 붙여 두면, 지금 REST API로 따로 긁어오는 숫자를 Claude에게 바로 물어볼 수 있다.

**바로 해볼 것:** README의 WordPress Playground 데모 링크를 열어 구조를 확인한 뒤, Claude Code에게 "내 플러그인에 읽기 전용 Ability 1개(이번 달 견적 목록)를 등록해줘"라고 시킨다.

**걸리는 점:** 설치만으로 끝나지 않는다. 플러그인에 Ability 코드를 추가해야 해서 프로젝트 단위 작업이다. 아직 v0.x라 마이그레이션 가이드가 여러 개 있을 만큼 API가 자주 바뀌었다. 고객 데이터가 걸려 있어 권한 설정을 신중히 해야 한다. Elementor 페이지 편집은 이 패키지의 범위가 아니다.
