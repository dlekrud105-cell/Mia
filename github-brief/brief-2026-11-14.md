### 1. keplergl/kepler.gl
링크: https://github.com/keplergl/kepler.gl  ⭐ 12,093 · 최근 푸시 2026-11-14

**뭐 하는 건데:** 위도·경도나 지역 단위 데이터를 올리면 점, 히트맵, 육각형 집계, 경계 채색 같은 지도 레이어로 그려주는 웹앱이다. README에 따르면 Claude Code 같은 MCP 클라이언트가 로컬 브리지를 거쳐, 열려 있는 지도 탭에 데이터를 넣고 레이어·필터·카메라 투어를 조작할 수 있다.

**미아한테 왜:** 서버브별 중위가격이나 임대수익률 지도를 지금은 손으로 만들거나 이미지로 짜깁기하고 있을 텐데, 그걸 CSV 하나 올리는 걸로 대신한다. 인스타 캐러셀이나 유튜브 썸네일에 넣을 지도 컷을 만드는 용도다.

**바로 해볼 것:** https://kepler.gl/demo 에 서버브명, 위경도, 가격 열이 있는 CSV를 끌어다 놓고 점 레이어를 가격 기준으로 색칠해 본다.

**걸리는 점:** README에서 확인한 것: 웹 데모가 있고, MCP 설정 가이드는 따로 문서(plugins/kepler.gl)에 있다(그 문서는 열어보지 않았음). 확인 못 한 것: 서버브 경계(폴리곤) 데이터는 직접 구해야 할 가능성이 높다(ABS 경계 파일 등). 데모의 이미지 내보내기 해상도가 인스타용으로 충분한지는 확인하지 못했다. 직접 개발 환경을 띄우려면 Node 24와 네이티브 모듈 빌드가 필요해서, 그건 Claude Code에게 맡겨야 한다.

### 2. chidiwilliams/buzz
링크: https://github.com/chidiwilliams/buzz  ⭐ 22,776 · 최근 푸시 2026-11-09 · MIT

**뭐 하는 건데:** 맥 앱(.dmg)으로 설치하는 오프라인 받아쓰기 도구다. 오디오·영상 파일이나 유튜브 링크를 넣으면 Whisper로 받아쓰고 TXT, SRT, VTT로 내보낸다. 화자 구분, 감시 폴더 자동 처리, CLI도 README에 나와 있다.

**미아한테 왜:** 비전에셋tv 영상의 자막 파일과 네이버 블로그용 원고 초안을 손으로 받아쓰거나 유료 받아쓰기 서비스로 뽑던 작업을 대신한다. 유피 애니메이션 대사 자막도 같은 방식으로 뽑을 수 있다.

**바로 해볼 것:** SourceForge에서 .dmg를 받아 설치한 뒤 최근 비전에셋tv 영상 하나를 넣고 SRT로 내보내 유튜브 스튜디오에 올려본다.

**걸리는 점:** README 기준 Apple Silicon 맥이 필요하다(인텔 맥은 구버전 1.4.5까지만 지원). 앱 서명이 안 돼 있다고 README에 적혀 있다(윈도우 기준 설명이고, 맥 Gatekeeper 경고 여부는 확인 못 함). 한국어 정확도는 README에 따로 언급이 없다. Whisper 자체는 한국어를 지원하지만, 부동산 용어나 지명이 얼마나 정확하게 나오는지는 직접 돌려봐야 안다.

### 3. jianchang512/pyvideotrans
링크: https://github.com/jianchang512/pyvideotrans  ⭐ 19,743 · 최근 푸시 2026-11-14 · GPL-3.0

**뭐 하는 건데:** 음성 인식, 자막 번역, TTS 더빙, 영상 합성을 한 흐름으로 처리한다. 단계마다 멈추고 직접 고칠 수 있다. GUI, CLI, WebUI를 모두 제공하고, 로컬 Faster-Whisper와 무료 Edge-TTS를 쓸 수 있다고 README에 나와 있다.

**미아한테 왜:** 한국어 비전에셋tv 영상에 영어 자막(또는 영어 더빙)을 붙여 호주 현지인이나 영어권 투자자용으로 다시 올리는 작업을, 손 번역 없이 CLI 한 줄로 처리한다. Buzz는 받아쓰기까지만 하고, 이건 번역과 더빙까지 이어진다는 점이 다르다.

**바로 해볼 것:** Claude Code에게 "pyvideotrans를 uv로 설치하고 이 SRT를 영어로 번역해줘(--task sts)"라고 시킨다. 처음에는 짧은 영상 하나로 자막 번역만 해본다.

**걸리는 점:** 맥에서는 미리 빌드된 앱이 없어서 소스로 설치해야 한다. README에 Python 3.10과 Homebrew ffmpeg 교체 절차가 있다. 번역 품질은 어떤 번역 엔진을 고르느냐에 달려 있다. Claude나 Gemini 키를 쓰면 사용량만큼 비용이 들고, 완전 무료 번역 옵션의 품질은 확인하지 못했다. 이 세션에서는 릴리스 정보를 조회하지 못해 최신 버전 번호는 확인 못 했다.
