### 1. kajisho5/ffmpeg-skill
링크: https://github.com/kajisho5/ffmpeg-skill  ⭐ 5,419 · 최근 푸시 2026-11-13 (검색 API의 pushed_at 기준)

**뭐 하는 건데:** Claude Code에 설치하는 스킬. 컷, 이어붙이기, 무음 제거, 9:16/1:1 리프레임, SRT 자막 굽기(카라오케 효과 포함), 음량 정규화(-14 LUFS), 릴스·쇼츠·유튜브 프리셋 내보내기 등 도구 42개를 로컬 ffmpeg로 실행하고, 끝나면 결과 파일의 길이·해상도·음량을 다시 측정해 플랫폼 규격(Reels, Shorts 등) 통과 여부를 알려준다. README 직접 확인: 한국어 자막은 글꼴을 자동으로 골라 주고(`--lang ko`), 한국어 필러("음", "어") 목록도 내장돼 있다.

**미아한테 왜:** Kling에서 뽑은 유피 클립이나 비전에셋tv 가로 영상을 "릴스용 9:16으로 잘라서 자막 넣고 음량 맞춰줘" 한 문장으로 Claude Code에 맡기면, 지금 CapCut에서 손으로 하는 반복 작업을 대신한다. 저장소에 있는 `tools/property_tour.py`(매물 투어 클립 조립)와도 같은 ffmpeg 기반이라 이어 쓰기 쉽다.

**바로 해볼 것:** 맥 터미널에서 `npx ffmpeg-skill` 후 `npx ffmpeg-skill doctor`로 이 맥에서 자막(`caption`)이 되는지 확인. 그 다음 유피 클립 하나로 "9:16 릴스로 만들어줘" 요청.

**걸리는 점:** README에 따르면 Homebrew 기본 `ffmpeg`에는 자막 필터(libass)나 일부 필터가 빠져 있을 수 있어 `ffmpeg-full` 설치가 필요할 수 있다(`doctor`가 알려줌). 음성 인식으로 자막을 자동 생성하려면 `faster-whisper` 등을 따로 설치해야 하고, 한국어 인식 품질은 README에 따로 나와 있지 않아 확인 못 함. 컷 위치를 "판단"하는 기능은 없고 시키는 대로 실행·검사만 한다.

### 2. vas3k/TaxHacker
링크: https://github.com/vas3k/TaxHacker  ⭐ 6,824 · 최근 푸시 2026-11-12 (검색 API의 pushed_at 기준)

**뭐 하는 건데:** 영수증 사진이나 인보이스 PDF를 올리면 LLM이 날짜·금액·가맹점·세금·품목을 뽑아 엑셀 같은 표에 저장한다. 거래일 기준 환율로 기본 통화 자동 환산, 카테고리·프로젝트·사용자 정의 필드, CSV 내보내기를 지원한다(README 직접 확인).

**미아한테 왜:** 호주 회계연도 세금 신고 때 업무 경비 영수증(차량, 휴대폰, 광고비 등)을 손으로 엑셀에 옮기는 일을 대신한다. "부동산 / 유어페인터 / 개인" 프로젝트로 나눠 쌓아두면 6월 말에 CSV로 바로 회계사에게 넘길 수 있다.

**바로 해볼 것:** Docker Desktop이 깔린 맥에서 README의 `docker-compose.yml` 받아 `docker compose up` → 영수증 사진 5장 올려서 추출 정확도 확인.

**걸리는 점:** README 스스로 "아직 초기 개발 단계, 위험은 본인 책임"이라고 써 있다. AI 추출에는 OpenAI·Gemini·Mistral API 키 또는 로컬 LLM(Ollama 등)이 필요하다. Gemini 무료 등급으로 충분한지는 확인 못 함. 어제 브리핑한 paperless-ngx(문서 보관·검색)와 일부 겹치지만, TaxHacker는 금액을 뽑아 표로 만드는 쪽이라 용도가 다르다. 호주 GST 항목을 기본으로 지원하는지는 README에 없음 — 사용자 정의 필드로 만들어야 할 수 있다.
