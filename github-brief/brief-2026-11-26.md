### 1. Junhan2/ztd-charts
링크: https://github.com/Junhan2/ztd-charts  ⭐ 394 · 최근 push 2026-11-19 (생성 2026-11-05)

**뭐 하는 건데:** 47종 차트(막대, 라인, 워터폴, 히트맵, 단계구분도 지도 등)를 React 컴포넌트 또는 JSON 사양으로 만든다. CLI(`ztd-charts-cli render spec.json --out a.png --scale 2`)와 MCP 서버(`claude mcp add ztd-charts -- npx -y ztd-charts-mcp`)로 PNG·SVG·HTML 렌더, CSV를 주면 어떤 차트가 맞는지 제안까지 한다. (README 확인)

**미아한테 왜:** 지금 캐러셀용 서버브별 중위가격·임대수익률 차트를 손으로 그리는 걸, Claude Code에 CSV를 주고 "Strathfield 강조한 막대차트 PNG로" 시키는 것으로 대신한다. `locale="ko-KR"`로 억/만 단위가 자동 적용되는 게 다른 차트 라이브러리와의 차이다. (README 확인)

**바로 해볼 것:** Claude Code에서 MCP 서버를 추가하고, 지난주 게시물에 쓴 데이터를 CSV로 넘겨 `suggest`로 차트 후보를 받아본다.

**걸리는 점:**
- 생성 3주 된 신생 프로젝트, 1인 개발. 장기 유지 여부는 모름.
- 실제 렌더를 이번 실행 환경에서 돌려보지 못했다(외부 npm 패키지 실행이 막힘). PNG 품질·한글 폰트 렌더는 미확인.
- 지도 차트가 호주 서버브 경계(GeoJSON)를 받을 수 있는지는 README에 안 나와 미확인.
- 기본 스타일이 "대시보드 카드" 톤이라 인스타 브랜드 색으로 테마 토큰을 바꿔야 할 가능성이 크다(추정).

**바로 해볼 것:** Releases에서 DMG를 받아 설치하고, 유피 Kling 클립 3~4개로 Settings > Magic에서 Claude 연결 후 한 문장 편집을 시켜본다.

**걸리는 점:**

- Apple Silicon + macOS 14 이상 필수. 로컬(Apple 기기 내) AI 옵션은 macOS 26 + Apple Intelligence 필요.
